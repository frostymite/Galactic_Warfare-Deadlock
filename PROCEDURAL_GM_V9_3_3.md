# Deadlock v9.3.3 — Procedural GM Personality Layer

This release keeps the game completely free and offline-first while making Story dialogue feel more like a live tabletop campaign.

## Added
- Freeform speech analysis for questions, demands, accusations, threats, bargains, apologies, reassurance, teasing, challenges, and explicit bluffs.
- Topic detection for Marr, Kade, credits, The Raven, trust, deals, intel, and danger.
- NPC-specific cadence, body-language narration, humor, directness, threat response, and follow-up style.
- Dynamic factual replies built from live campaign state instead of only static dialogue tables.
- Memory callbacks for the rifle return, Marr payout discussion, staged turn-in, field history, active Kade contract, and caught lies.
- Persistent anti-repetition GM state so recent lines and stage beats are less likely to repeat.
- Small relationship reactions to freeform tone even when no skill check was rolled.
- Contextual in-character Rovan response choices after NPC dialogue.

## Rules boundary
The GM layer can narrate and roleplay, but contract progress, ship condition, credits, target status, and other mechanical state remain controlled by the consequence engine.
