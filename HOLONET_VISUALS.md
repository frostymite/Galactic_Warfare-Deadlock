# Deadlock v9.2.1 — Holonet Visual Layer

Added on top of the stable v9.2 QA build.

## Holonet Operations
A completely offline simulated communications layer:
- encrypted local transmissions
- procedural contact / unknown-signal messages
- messages remain unverified until **Log to Story**
- offline relay-mesh visual
- BountyNet snapshot
- hyperspace navigation readout

## Hyperspace navigation
The Galaxy page now includes:
- animated local route plot
- corridor quality
- route risk
- destination selector
- The Raven current-position marker
- animated hyperspace path

Route plots are navigation UI, not automatic campaign canon.

## Bounty holo-puck
Generated bounty leads now appear in a rotating holographic bounty-puck reveal before the normal dossier controls.

## Raven holographic schematic
The Ship page includes a live schematic with interactive nodes for:
- engines
- maneuvering thrusters
- hyperdrive
- encrypted comms
- shield overcharge
- weapons bench
- prisoner compartment
- hidden storage

Nodes use the same real system state as the rest of Deadlock OS.

## Aurebesh-inspired flavor
Decorative cipher/glyph strips are used as visual flavor while all operational controls remain readable in English.

## Offline guarantee
All features above are CSS / JavaScript / cached local data. No internet connection is required.
