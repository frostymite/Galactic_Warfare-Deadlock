# Android No-Signal Setup

## Best setup
1. Host the Deadlock folder on HTTPS.
2. Open it in Chrome on Android.
3. Install it using **Install App** / **Add to Home screen**.
4. Open the installed app once while still online.
5. Confirm the Story tab says **OFFLINE DIRECTOR**.
6. Export a JSON campaign backup.

At this point, the main game is designed to continue with airplane mode enabled.

## What works offline
- Story Mode
- procedural NPC dialogue
- NPC memory
- relationship state
- random encounters
- skill checks
- combat
- target dossiers
- bounty generator
- contracts
- credits
- galaxy / mission map
- The Raven systems
- dogfights
- inventory
- journal
- factions
- dice
- saves
- import/export
- animations
- synthesized UI sounds
- haptics where supported

## What does not require a connection
The offline Narrative Director does not call any external server.

## Optional connection-only feature
Online AI Enhancement requires the optional Story Bridge.
If it is unavailable, the campaign remains playable offline.
