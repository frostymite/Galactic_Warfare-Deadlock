# v5 Cinematic Feature Map

## Combat
- Initiative timeline updates every turn.
- Combatants render as animated holographic portrait cards.
- Tap an enemy card to select that target.
- Open Weapon Wheel to choose Blackwake, Luna, or Sol.
- MODE cycles that weapon's established modes.
- FIRE uses the selected weapon against the selected target.
- Natural 20 triggers CRITICAL graphics and haptics.
- Damage application remains explicit so the UI does not silently force combat rules.

## Weapon FX
Blackwake
- Heavy: white/gold heavy impact
- Shield-Punch: cyan expanding shockwave

Luna / Sol
- Energy: cyan beam
- Lethal: red impact wash
- Explosive: radial blast + screen shake

## Bounties
Generated leads remain marked Unverified.
ACCEPT CONTRACT:
1. Saves the generated target dossier.
2. Creates a new active contract.
3. Displays the full-screen BOUNTY ACQUIRED sequence.
4. Adds the event to the tactical feed.

## Android
All primary combat controls use minimum touch-size buttons.
The weapon wheel is modal and centered for thumb use.
On narrow screens, the main app navigation remains fixed at the bottom.
