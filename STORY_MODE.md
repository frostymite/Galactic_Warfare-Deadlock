# Story Mode Feature Map

## Interactive loop
1. Read narration/dialogue.
2. Tap one of 3–5 choices OR write any action.
3. Optional skill check resolves inside the app.
4. Local engine or AI Story Bridge generates the next beat.
5. New narration and dialogue are appended to persistent history.
6. Approved state updates can affect the rest of Deadlock OS.

## Linked systems
Story responses can update:
- contract progress
- contact trust
- credits
- target status
- journal
- location
- danger
- combat start state

## NPC dialogue
Seeded NPC voices:
- Dren Voss — dry, sharp, competitive
- Nera Kade — controlled and businesslike
- Renn — cautious and pragmatic
- Jessa — direct and field-minded

All NPC profiles can be edited in the campaign JSON.

## Skill checks
Story checks use:
d20 + a simple bonus derived from the 0–100 skill score.

This is a dashboard mechanic, not a claim about official D&D rules, and can be changed later.
